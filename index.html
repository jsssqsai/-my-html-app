使用说明

💰 销售功能

  • 点击"+"按钮添加商品
  • 选择商品后可设置优惠价
  • 点击商品名称可编辑明细
  • 点击×按钮删除商品
  • 点击"预览打印"查看小票效果
  • 确认后打印并统计营业额

📦 商品管理

  • 点击"+"按钮添加新商品
  • 上传商品照片方便识别
  • 设置单价和计量单位
  • 点击✏️编辑商品信息
  • 点击🗑️删除商品

📊 统计功能

  • 显示每日营业额统计
  • 选择日期查看历史数据
  • 查看当日销售明细
  • 导出数据进行备份
  • 导入数据恢复备份

⚙️ 店铺设置

  • 设置店铺名称
  • 设置店铺地址和电话
  • 上传店铺二维码
  • 信息会显示在小票上

💡 实用技巧

  • 熟客可输入优惠价
  • 定期导出数据备份
  • 打印后才会计入营业额
  • 清空不会影响统计数据

🖨️ 蓝牙打印说明

连接步骤：

  1. 确保打印机已开启并处于可发现模式
  2. 确保 iPad 蓝牙已开启
  3. 点击"预览打印" → 选择"蓝牙打印"
  4. 点击"连接"按钮，在弹出的设备列表中选择打印机
  5. 等待连接成功后，点击"确认打印"

iPad 用户特别注意：

  • ⚠️ iPad 上的 Chrome 和 Safari 不支持蓝牙打印！
  • 请使用 Bluefy 浏览器（App Store 免费下载）
  • Bluefy 是专门为 iOS 设计的支持 Web Bluetooth 的浏览器

注意事项：

  • 电脑用户：请使用 Chrome 或 Edge 浏览器
  • iPad 用户：请使用 Bluefy 浏览器
  • 需要通过 HTTPS 或 localhost 访问
  • 支持的打印机：芯烨 XPrinter 系列
  • 如果连接失败，请重启打印机后重试
