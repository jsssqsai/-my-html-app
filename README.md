# 蔬菜小票打印系统

专为iPad设计的蔬菜销售小票打印系统，帮助菜贩管理商品、打印销售清单、统计每日营业额。

## 功能特点

- 📦 商品管理：添加/编辑/删除商品，支持上传照片
- 💰 销售开单：快速添加商品到销售单，自动计算金额
- 🖨️ 小票打印：适配58mm/80mm热敏小票打印机
- 📊 营业统计：按日期查看销售额和销售明细
- 💾 数据备份：支持导出/导入JSON数据
- 📱 PWA支持：可安装到iPad主屏幕，离线可用

## 安装方法

### 方法一：iPad Safari安装（推荐）

1. 确保iPad和服务器在同一WiFi网络
2. 在服务器上启动：`python -m http.server 8080`
3. iPad Safari访问：`http://服务器IP:8080`
4. 点击分享按钮 → "添加到主屏幕"
5. 点击"添加"完成安装

### 方法二：本地文件打开

直接用浏览器打开 `index.html` 文件即可使用（部分功能如Service Worker需要HTTP服务器）

## 使用说明

1. **销售页面**：点击"+"添加商品到销售单，调整数量后打印小票
2. **商品页面**：管理商品库，添加/编辑/删除商品
3. **统计页面**：查看每日营业额，导出/导入数据备份
