# 蔬菜小票打印系统 v2.0

专为 iPad 设计的蔬菜销售小票打印系统，帮助菜贩管理商品、打印销售清单、统计每日营业额。

## 🚀 快速开始

### 方法一：本地测试（电脑浏览器）

直接用浏览器打开 `index.html` 文件即可使用。

### 方法二：iPad 部署（推荐）

1. 将项目文件夹传到服务器或电脑
2. 启动本地服务器：
   ```bash
   python -m http.server 8080
   ```
3. iPad Safari 访问：`http://服务器IP:8080`
4. 点击分享按钮 → "添加到主屏幕"
5. 从主屏幕打开应用，可离线使用

## 📱 功能说明

### 💰 销售页面
- 点击右下角"+"添加商品到销售单
- 支持搜索快速找到商品
- 点击商品名称可编辑明细（改价、改数量）
- 点击 × 按钮删除商品
- 预览打印效果后确认打印

### 📦 商品管理
- 搜索框实时过滤商品
- 排序下拉框：默认/名称/价格
- 点击商品添加到销售单
- 点击 ✏️ 编辑商品信息
- 点击 🗑️ 删除商品

### 📊 统计页面
- 显示每日营业额
- 选择日期查看历史数据
- 查看当日销售明细
- 导出/导入数据备份

### ⚙️ 店铺设置
- 设置店铺名称、地址、电话
- 上传店铺二维码
- 信息会显示在小票上

---

## 🖨️ 打印设置

### 支持的打印机
- 芯烨 XP58IIL（58mm 热敏）
- 佳博 GP-58（58mm 热敏）
- 其他 58mm/80mm 热敏小票打印机

### iPad 打印步骤
1. 确保打印机与 iPad 连接（蓝牙/USB/网络）
2. 点击"预览打印" → "确认打印"
3. 系统打印面板选择打印机
4. 纸张大小选择 58mm 或 80mm
5. 关闭"页眉和页脚"选项
6. 点击打印

详细设置请参考 `INSTALL.md`

---

## 💾 数据管理

### 数据存储
- 所有数据存储在浏览器 localStorage
- 商品数据、销售记录、店铺信息自动保存

### 备份与恢复
1. 进入"统计"页面
2. 点击"导出数据"下载 JSON 备份文件
3. 需要恢复时点击"导入数据"选择备份文件

## 🔧 技术信息

- **技术栈**：HTML5 + CSS3 + JavaScript（纯前端）
- **数据持久化**：LocalStorage
- **PWA 支持**：可安装到主屏幕，离线可用
- **适配设备**：iPad（竖屏）、iPhone、Android 平板、桌面浏览器

---

## ⚠️ 注意事项

1. **首次使用**：建议先设置店铺信息
2. **定期备份**：重要数据请定期导出备份
3. **打印要求**：需要连接支持 58mm/80mm 的热敏小票打印机
4. **iOS 版本**：建议 iOS 13 以上
5. **图标文件**：`icons/` 目录需要自行添加 PNG 图标（尺寸：72x72 到 512x512）
